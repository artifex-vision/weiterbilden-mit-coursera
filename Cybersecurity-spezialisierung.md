# Cybersecurity-Spezialisierung: Dein Weg zum Security-Experten

## 🎯 Lernziel
Vom Security-Anfänger zum Cybersecurity Professional in 10-15 Monaten

## 📋 Voraussetzungen
- Grundlegende IT-Kenntnisse (hilfreich aber nicht zwingend)
- Interesse an IT-Sicherheit und ethischem Hacking
- Zeitinvestition: 10-20 Stunden/Woche
- Analytisches Denken und Problemlösungsfähigkeit

---

## 🗺️ Detaillierter Lernpfad

### Phase 1: Grundlagen (Monat 1-4)

#### Kurs 1: Google Cybersecurity Professional Certificate ⭐⭐⭐
**Dauer:** 6 Monate bei 7h/Woche (oder 3-4 Monate bei 12-15h/Woche)
**Anbieter:** Google
**Level:** Beginner-Friendly

**Module:**
1. **Foundations of Cybersecurity**
   - Security Domains (CIA Triad)
   - Threats, Risks, Vulnerabilities
   - Security Frameworks (NIST)
   - Ethics in Cybersecurity

2. **Play It Safe: Manage Security Risks**
   - CISSP Security Domains
   - Risk Management
   - Security Audits
   - Security Frameworks & Controls

3. **Connect and Protect: Networks and Network Security**
   - Network Architecture
   - Network Protocols (TCP/IP, DNS, HTTP)
   - Network Attacks
   - Network Hardening

4. **Tools of the Trade: Linux and SQL**
   - Linux Command Line
   - File Permissions
   - SQL Queries
   - Database Security

5. **Assets, Threats, and Vulnerabilities**
   - Asset Classification
   - Threat Modeling
   - Vulnerability Assessment
   - Authentication & Authorization

6. **Sound the Alarm: Detection and Response**
   - Incident Detection
   - SIEM Tools (Splunk, Chronicle)
   - Incident Response Lifecycle
   - Forensics Basics

7. **Automate Cybersecurity Tasks with Python**
   - Python for Security
   - Automation Scripts
   - Security Tools Development

8. **Put It to Work: Prepare for Cybersecurity Jobs**
   - Portfolio Development
   - Resume Building
   - Interview Preparation

**Skills erworben:**
- Security Fundamentals
- Network Security
- Linux & SQL
- SIEM Tools
- Python for Security
- Incident Response

**Projekt-Ideen:**
1. Security Audit Report für ein fiktives Unternehmen
2. Network Security Analysis
3. Python Security Automation Script (z.B. Log Analyzer)

## 💡 Pro-Tipps für Cybersecurity

1. **Hands-on > Theory:** Security is practical! Lab time is crucial
2. **Legal Ethics:** ALWAYS get permission before testing
3. **Document Everything:** Keep detailed notes, write-ups
4. **Stay Updated:** Security landscape changes daily
5. **Community:** Join Discord servers, Twitter infosec community
6. **CTFs:** Great for learning & networking
7. **Homelab:** Setup your own lab environment
8. **Certifications Matter:** In security, certs open doors
9. **Specialize Eventually:** Pick a niche (AppSec, Cloud, Red Team, etc.)
10. **Never Stop Learning:** Security is a continuous journey

## ⚠️ Wichtige Hinweise

### Ethical Hacking:
- **NIEMALS** unauthorized testing!
- Only test systems you own or have explicit permission
- Hack The Box, TryHackMe = Legal practice environments
- Violating laws can end your career before it starts

### Security Career Path:
- **Blue Team** (Defense): SOC Analyst → Incident Responder → Security Engineer
- **Red Team** (Offense): Pen Tester → Red Team Operator → Security Researcher
- **Purple Team** (Both): Security Analyst → Security Architect
