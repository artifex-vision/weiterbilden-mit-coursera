# IT-Spezialisierung: Dein Weg zum IT-Experten

## 🎯 Lernziel
Vom IT-Anfänger zum Cloud & DevOps Experten in 12-18 Monaten

## 📋 Voraussetzungen
- Grundlegende Computer-Kenntnisse
- Keine Programmiererfahrung notwendig
- Zeitinvestition: 10-20 Stunden/Woche

---

## 🗺️ Detaillierter Lernpfad

### Phase 1: Grundlagen (Monat 1-4)

#### Kurs 1: Google IT Support Professional Certificate ⭐
**Dauer:** 6 Monate bei 5h/Woche (oder 3 Monate bei 10h/Woche)
**Link:** Coursera - Google IT Support

**Module:**
1. **Technical Support Fundamentals**
   - Computer Assembly
   - Operating Systems (Windows, Linux, macOS)
   - Networking Basics
   - Software Management

2. **Computer Networking**
   - TCP/IP Model
   - DNS, DHCP
   - Network Troubleshooting
   - Cloud Computing Basics

3. **Operating Systems**
   - Windows Administration
   - Linux Command Line
   - File Systems
   - Process Management

4. **System Administration**
   - Active Directory
   - User Management
   - Backup & Recovery
   - Security Basics

5. **IT Security**
   - Encryption
   - Authentication
   - Network Security
   - Best Practices

**Skills erworben:**
- Windows & Linux Administration
- Networking Fundamentals
- Troubleshooting
- IT Support Best Practices

**Projekt-Idee:**
- Erstelle eine Dokumentation für ein fiktives Unternehmen: Setup eines neuen Mitarbeiter-PCs mit allen notwendigen Tools und Sicherheitseinstellungen

---

#### Kurs 2: Introduction to Cloud Computing
**Dauer:** 10 Stunden
**Anbieter:** IBM

**Inhalte:**
- Cloud Service Models (IaaS, PaaS, SaaS)
- Cloud Deployment Models
- Major Cloud Providers (AWS, Azure, Google Cloud)
- Cloud Security & Economics

**Projekt-Idee:**
- Erstelle eine Präsentation: Cloud Migration Strategy für ein kleines Unternehmen

---

#### Kurs 3: Google IT Automation with Python ⭐
**Dauer:** 6 Monate bei 5h/Woche
**Link:** Coursera - Google

**Module:**
1. **Crash Course on Python**
   - Python Basics
   - Data Structures
   - Object-Oriented Programming

2. **Using Python to Interact with OS**

   - Regular Expressions
   - Process Management

3. **Git and GitHub**
   - Version Control

   - Code Review

4. **Troubleshooting and Debugging**
   - Error Handling
   - Logging
   - Testing

5. **Configuration Management and Cloud**
   - Puppet
   - Cloud Infrastructure
   - Automation at Scale

**Skills erworben:**
- Python Programming
- Automation Scripts
- Git/GitHub
- Configuration Management

**Projekt-Ideen:**
1. Automatisiertes Backup-Script für Server
2. Log-File Analyzer mit Python
3. System Health Check Dashboard

**Dauer:** 3 Monate bei 4h/Woche

3. **AWS Database Services**
   - RDS, DynamoDB
   - Database Migration
   - Performance Optimization

4. **AWS Security**
   - IAM

   - Encryption

**Skills erworben:**
- AWS Infrastructure
- Cloud Architecture
- Security Best Practices

**Projekt-Ideen:**

3. Auto-Scaling Web Server Setup

## 💼 Karrierepfad

### Entry-Level (Nach 3-6 Monaten)
**Positionen:**
- IT Support Specialist
- Junior System Administrator
- Help Desk Technician

**Gehalt:** €35.000 - €45.000

**Job Requirements:**
- Google IT Support Certificate
- Grundkenntnisse Networking
- Windows/Linux Basics

### Mid-Level (Nach 9-12 Monaten)
**Positionen:**
- System Administrator
- Cloud Engineer
- DevOps Engineer (Junior)

**Gehalt:** €50.000 - €70.000

**Job Requirements:**
- Python Automation Skills
- AWS/Azure Grundkenntnisse
- 6-12 Monate Erfahrung

### Senior-Level (Nach 15-24 Monaten)
**Positionen:**
- Cloud Architect
- Senior DevOps Engineer
- Site Reliability Engineer

**Gehalt:** €75.000 - €100.000+

**Job Requirements:**
- AWS/Azure Certification
- Container & Kubernetes Experience
- CI/CD Pipeline Experience
- Portfolio mit mehreren Projekten
