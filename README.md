# Weiterbilden mit Coursera 🎓

**Der komplette Leitfaden für deine IT-, AI- und Cybersecurity-Karriere!**

## 📖 Übersicht

Dieses Repository enthält umfassende Lernpfade und Karriere-Guides für drei hochgefragte Tech-Bereiche:

- **🖥️ IT-Spezialisierung** - Werde Cloud & DevOps Experte
- **🤖 AI-Spezialisierung** - Werde Machine Learning Engineer
- **🔐 Cybersecurity-Spezialisierung** - Werde Security Professional

Jeder Lernpfad ist strukturiert aufgebaut mit:
✅ Konkreten Kursempfehlungen  
✅ Zeitaufwand und Zeitplanung  
✅ Praktischen Projekten für dein Portfolio  
✅ Job-Suche Strategien  
✅ Gehaltserwartungen  
✅ Strukturierter Lernmethodik

## 🎯 Strukturiertes Lernen

Das Programm basiert auf der **5-Schritte-Methode**:

1. **⏰ Wochenplanung** - Konsistente Lernroutine etablieren
2. **📚 Aktives Lernen** - 30% Videos, 50% Praxis, 20% Review
3. **💻 Projekt-basiert** - Portfolio mit echten Projekten aufbauen
4. **👥 Community** - Networking und Peer-Learning
5. **📊 Kontinuierliche Bewertung** - Fortschritt tracken

Detaillierte Anleitung: [Programm-Übersicht](./program-overview.md#-strukturiertes-lernen-die-5-schritte-methode)

## 📊 Investition & ROI

### Kosten:
- **Coursera Plus:** €399/Jahr (unbegrenzter Zugang)
- **Einzelkurse:** €30-99/Monat

### Zeit-Investition:
| Spezialisierung | Bei 10h/Woche | Bei 20h/Woche |
|-----------------|---------------|---------------|
| IT | 12-18 Monate | 6-9 Monate |
| AI | 20-30 Monate | 10-15 Monate |
| Cybersecurity | 10-15 Monate | 5-8 Monate |

### Return on Investment:
Einstiegsgehälter: €45k-€55k  
Nach 2 Jahren: €65k-€95k  
Senior Level: €80k-€140k+
