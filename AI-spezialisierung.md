# AI-Spezialisierung: Dein Weg zum AI/ML-Experten

## 🎯 Lernziel
Vom Programmier-Anfänger zum Machine Learning Engineer in 15-24 Monaten

## 📋 Voraussetzungen
- Grundlegende Mathematik-Kenntnisse (Abitur-Niveau)
- Keine Programmiererfahrung notwendig (aber hilfreich)
- Zeitinvestition: 15-25 Stunden/Woche
- Neugier und analytisches Denken

---

## 🗺️ Detaillierter Lernpfad

### Phase 1: Grundlagen (Monat 1-6)

#### Kurs 1: Python for Everybody Specialization ⭐
**Dauer:** 8 Monate bei 3h/Woche (oder 4 Monate bei 6h/Woche)
**Anbieter:** University of Michigan
**Instructor:** Dr. Charles Severance

**Module:**
1. **Programming for Everybody (Getting Started with Python)**
   - Variables, Expressions
   - Conditional Execution
   - Functions
   - Loops and Iterations

2. **Python Data Structures**
   - Strings, Lists, Dictionaries
   - Tuples
   - File Handling

3. **Using Python to Access Web Data**
   - Regular Expressions
   - Networks & HTTP
   - Web Scraping
   - JSON/XML

4. **Using Databases with Python**
   - SQL Basics
   - Database Design
   - Python + SQLite

5. **Capstone: Retrieving, Processing, and Visualizing Data**
   - End-to-End Project

**Skills erworben:**
- Python Programming (Grundlagen & Fortgeschritten)
- Data Handling
- Web Scraping
- SQL

**Projekt-Ideen:**
1. Web Scraper für Job-Postings
2. Twitter Sentiment Analyzer
3. Personal Finance Tracker mit Database

## 💡 Pro-Tipps

1. **Kaggle ist dein Freund:** Competitions, Datasets, Kernels lernen
2. **Paper-Implementierung:** Wähle 2-3 Papers und implementiere sie
3. **Blog schreiben:** Dokumentiere dein Lernen (hilft beim Verstehen!)
4. **Community:** Twitter ML Community ist Gold wert
5. **Geduld:** ML ist komplex, don't give up!
6. **Mathe nicht auslassen:** Es hilft enorm beim Debugging
7. **Deploy early:** Ein deployed model > 10 jupyter notebooks
